## ⚙️ Методология

### 1. Признаковое пространство (33 признака)

| Группа | Признаки | Индексы |
|--------|----------|---------|
| Энергетические | Energy, Early fraction, Tail ratio, Tail energy | 0–3 |
| Статистические | STD, Sharpness, Asymmetry, FWHM, Rise time | 4–8 |
| PSD | PSD для 14 длин ворот (5–200) | 9–15 |
| Градиенты PSD | Разности PSD для разных ворот | 16–20 |
| Отношения PSD | Early/late PSD ratios | 21–22 |
| Временные | Decay τ, Fit quality (R²) | 23–24 |
| Моменты | Skewness, Kurtosis | 25–26 |
| Форма | Energy density, Compactness, Tail ratios | 27–32 |

### 2. Композитный скор

$$ \text{Score} = \sum_{i=1}^{33} w_i \cdot X_{\text{norm}}^{(i)} $$

**Ключевые веса (эмпирическая оптимизация по silhouette score):**
- `EARLY +2.4` — нейтроны имеют бóльшую раннюю долю
- `PSD_GRAD1 +1.6` — градиент PSD (ключевой дискриминатор)
- `PSD40 +0.7` — Pulse Shape Discrimination
- `DECAY_TAU +0.5` — время высвечивания

### 3. Детекция аномалий (кластер 2)

| Критерий | Порог | Обоснование |
|----------|-------|-------------|
| Низкая энергия | < 3-го перцентиля | Шум/выбросы |
| Плохое качество фита | R² < 5-го перцентиля | Искажённая форма |
| Экстремальное время спада | \|z\| > 2.5σ | Аномальная компонента |
| Аномальная асимметрия | \|z\| > 3.0σ | Перекос формы |
| Экстремальное PSD40 | \|z\| > 3.0σ | Нестандартная форма |
| Экстремальный FWHM | \|z\| > 3.0σ | Сбой дискретизации |

**Сигнал аномален, если выполняется ≥2 критериев**
